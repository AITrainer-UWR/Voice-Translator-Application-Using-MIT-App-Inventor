# Voice-Translator-Application-Using-MIT-App-Inventor

## 🎙️Voice Translator Application

**📌 Overview**

The Voice Translator Application is a mobile app developed using MIT App Inventor that enables real-time translation of spoken English into multiple languages. The app provides both text and voice output, offering a complete voice-to-voice translation experience.

**🌍 Supported Languages**

Users can select a target language using a ListPicker component. The currently supported languages are:

* French (fr)

* Spanish (es)

* German (de)

* Malayalam (ml)

* Hindi (hi)

* Tamil (ta)

**⚙️ How It Works**

* The user selects a target language from the ListPicker.

* The user clicks the Translate button.

* Google Speech Recognition is activated through the SpeechRecognizer component.

* The user speaks in English.

* The spoken voice is converted into English text.

* The Translator component translates the text into the selected language.

* The translated text is displayed on the screen.

* The Text-to-Speech component reads the translated text aloud.

**🛠️ Technologies Used**

* MIT App Inventor

* SpeechRecognizer

* Translator Component

* Text-to-Speech

* Google Speech Services

* Android Smartphone

**🎯 Key Features**

* Real-time voice translation

* Multiple language support

* Text and voice output

* Simple and user-friendly interface

* No traditional coding required

**👥 Use Cases**

* Travelers communicating in foreign countries

* Students and teachers for learning languages

* Beginners exploring mobile app development

* Quick and simple language translation needs

**🚀 Conclusion**

This project demonstrates how speech recognition, language translation, and text-to-speech technologies can be effectively integrated into a mobile application using visual programming. The Voice Translator Application provides a practical, beginner-friendly solution to overcome language barriers and highlights the capabilities of MIT App Inventor in building real-world applications.
